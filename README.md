### The Internship Arc

Nine months at BiUP Technologies turning unstructured chaos into structured pipelines. Built a RAG system (FastAPI, LLMs, Pinecone) that reads PDFs, DOCX, XLSX, and PPTX files and cut manual data extraction time by 90% — basically did everyone's least favorite task for them. Also built a YOLOv8 + Flask system that judges vehicle photos in under 60ms, which remains the fastest anyone has ever judged anything of mine.
